# Why These E-Ink BSB Editions Were Created

The **Berean Standard Bible (BSB)** is a faithful, transparent modern English translation dedicated to the public domain. However, readers who download the standard `.epub` file from the web onto dedicated e-readers often encounter frustrating limitations.

### Source & Version of the Text

* **Text & Version:** **Berean Standard Bible (BSB), 3rd Printing** (complete 66-book canonical text).
* **Upstream Release:** **October 2, 2026** (incorporating translation committee errata fixes).
* **Source Archive:** Built directly from official **USFM 3.1** markup (`bsb_usfm.zip`) published by **Bible Hub** and **Berean Bible**—not converted from an existing EPUB.

### The Problem with the Standard EPUB

The generic online EPUB was designed for desktop reading apps rather than specialized E-Ink hardware. On dedicated e-readers, it suffers from several critical issues:

1. **Broken Table of Contents:** Chapter menus are completely flat. Reaching books like Romans or Revelation requires scrolling past more than 1,300 items.
2. **One-Way Footnotes:** Tapping a footnote jumps to the chapter's end with no link back to your verse, leaving you stranded.
3. **Sluggish Performance:** Bloated chapter files cause slow page turns and memory freezes on pocket e-readers.
4. **Distracting Typography:** Faint grays and uneven verse spacing cause line-height jitter on black-and-white screens.

### How These Editions Differ

Rather than patching that EPUB, this project recompiled the Bible from raw USFM source markup:

* **Fast Navigation:** Jump to any book or chapter in seconds via button-friendly 2-stage menus (XTEINK X4) or touch-friendly nested menus (Kobo Clara / KOReader).
* **Effortless Footnotes:** Instant pop-up notes or dedicated end-of-book notes with direct return links to your verse.
* **Tuned for E-Ink:** Crisp pure-black typography, uniform verse numbers, and proper poetic indentation.
